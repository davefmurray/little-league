### 1. [warning] Converter preflight misses a symlink above the output directory

**Location:** `tools/analysisart32_convert.py:544`, `:557`; `walk_down()` at `:531`; installation at `:629`.

**Reproduction:** Create a real scratch directory and a sibling symlink `linked -> real`, then select `--out linked/new-output`, where `new-output` does not yet exist. `protect_outputs()` accepts all eight planned destinations. `out.is_symlink()` is false, and `walk_down(out, target)` starts at `out`, so neither check examines `linked`. The existing stage guards resolve and reject protected targets, but do not reject this otherwise ordinary linked ancestor.

I reproduced the accepted guard directly and then ran the unmodified converter `main()`, registry comparison, both preflights and installer. That installed all eight registered outputs into `real/new-output` through the linked path. To obey the prohibition on Git commands, only `regenerate()` was replaced in memory with the installed byte batch after independently checking its complete registry equality, reconverting the registered render and rebuilding the exact ROM. This is an installer/guard reproduction, not a fresh-pxl regeneration claim. No protected file was overwritten.

**Impact:** This violates the explicit production contract to reject symlinks in output ancestors before any installation. A linked ancestor can redirect the entire batch into another directory even though the converter claims to reject links on the way to each planned file. The registered bytes and selected ROM remain correct; the defect concerns destination ownership/refusal, not the card composition. The probe already checks all ancestors in `Outputs.__init__`, so the two writers enforce different contracts.

**Suggested correction, report only:** Inspect ancestors above `out` as well as `out` and the paths beneath it. Add a scratch-only negative control with an ancestor symlink and a missing output directory. Keep normal fresh build/temp destinations accepted, and account for the platform's canonical temporary root. No art or assembly change is indicated.

**Evidence:** [direct guard result](ancestor-guard.json), [installer reproduction](ancestor-installer.py), [installer output](ancestor-installer.txt), [installed-byte check](ancestor-installer.json). The reproduction uses only disposable scratch paths and never hardlinks a real tracked input.
